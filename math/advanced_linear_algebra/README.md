# Advanced Linear Algebra

## Description
This project covers advanced linear algebra concepts implemented in Python.
It explores determinants, inverses, eigenvalues, and matrix definiteness.

## Requirements
- Ubuntu 16.04 LTS
- Python 3.5
- NumPy 1.15
- pycodestyle 2.5

## Files
| File | Description |
|------|-------------|
| `0-determinant.py` | Calculates the determinant of a matrix |
