# Calculus

This directory contains solutions to intra-net Calculus project.

## Multiple Choice Files
Answer files for sigma/pi notation, derivatives, and integral questions.

## Python Scripts

### 9-sum_total.py
`summation_i_squared(n)` — computes ∑(i=1→n) i² using the closed-form formula n(n+1)(2n+1)/6.

### 10-matisse.py
`poly_derivative(poly)` — computes the derivative of a polynomial represented as a coefficient list.

### 17-integrate.py
`poly_integral(poly, C=0)` — computes the integral of a polynomial with integration constant C.
